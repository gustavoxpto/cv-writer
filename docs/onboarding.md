# Onboarding

1. Read `CLAUDE.md` — the rules the AI harness follows here.
2. Read `README.md`'s folder map.
3. Skim `specs/adr/0001-record-architecture-decisions.md` for the reasoning behind the setup.
4. To start a feature: copy `specs/templates/spec-template.md` into `specs/features/`, fill it
   in, get sign-off, *then* start writing failing tests in `tests/`.
5. Secrets: read `docs/security.md` before touching anything credential-shaped.
